# 嗷嗷状态栏歌词

<img src="Resources/AppIcon.png" width="180" alt="嗷嗷状态栏歌词图标">

一个极简的 macOS Apple Music 状态栏歌词工具。它会自动读取当前歌曲和播放进度，匹配同步歌词，并将当前歌词直接显示在 macOS 状态栏中。

[下载精简版 ZIP](https://github.com/sange1022/aow-statusbar-lyrics/releases/latest/download/aow-statusbar-lyrics-1.4.1.zip) · [全部版本和 DMG 安装包](https://github.com/sange1022/aow-statusbar-lyrics/releases)

适用于 Apple Silicon Mac，macOS 13 或更新版本。ZIP 约 0.8 MB，无额外运行依赖。

## 功能

- 自动识别 Apple Music 当前歌曲
- 状态栏逐行同步显示歌词
- 精确匹配失败时，按歌名、歌手和时长自动寻找最合适的歌词
- 暂停、停止和换歌状态自动响应
- Apple Music 退出后，歌词应用自动退出
- 无 Dock 图标，不打扰桌面

## 安装教程

1. 从发布附件下载 DMG（GitHub 上文件名为 `aow-statusbar-lyrics-*.dmg`）。
2. 双击打开 DMG。
3. 把“嗷嗷状态栏歌词”拖入旁边的“应用程序”文件夹。
4. 打开 Apple Music 并开始播放歌曲。
5. 前往“应用程序”，打开“嗷嗷状态栏歌词”。

也可以下载体积更小的 ZIP，解压后把 `.app` 拖入“应用程序”。更新时先退出旧版，再替换应用。

本应用暂未经过 Apple 公证。首次打开如果提示无法验证开发者：

1. 在 Finder 的“应用程序”中找到“嗷嗷状态栏歌词”。
2. 按住 Control 点击应用，选择“打开”。
3. 在弹出的对话框中再次选择“打开”。

也可以前往“系统设置 → 隐私与安全性”，在页面下方选择“仍要打开”。

## 首次授权

第一次运行时，macOS 会询问是否允许应用控制“音乐”，请选择“允许”。这是读取歌曲名称、歌手、专辑和播放进度所必需的。

如果误点了拒绝：

1. 打开“系统设置 → 隐私与安全性 → 自动化”。
2. 找到“嗷嗷状态栏歌词”。
3. 打开它对“音乐”的访问权限，然后重新启动应用。

## 使用方法

- 歌词会出现在屏幕顶部状态栏。
- 1.3.1 起歌词区域固定加宽至最多 520 点，小屏幕自动缩窄；单行居中，超长歌词末尾省略，悬停查看完整内容。
- 点击歌词，可查看当前歌曲信息或退出应用。
- 按住 Command 拖动歌词，可以调整它在状态栏中的位置。
- 切歌后会自动重新匹配歌词。
- 退出 Apple Music 后，歌词应用也会自动退出。

歌词匹配需要网络连接。没有匹配结果时会显示“暂无匹配的同步歌词”；网络失败最多自动重试两次，也可以点击菜单中的“重新匹配歌词”。失败结果不会永久缓存。

### 1.3 匹配优化

- 优先查询缓存接口，再逐级搜索，最后尝试外部检索。
- 兼容合作歌手、重制版、标点与大小写差异；保留 Live、Remix 等版本信息。
- 中英文艺名不同的情况下，只有歌名相同、时长相差不超过两秒且只有一个歌手候选，才尝试回退匹配。菜单会标明候选歌手，请核对；该推断仍可能误配。
- 换歌或重新匹配会取消旧请求，防止旧结果覆盖当前歌曲。

歌词来源目前只有 LRCLIB，因此无法保证所有歌曲都有同步歌词。只有纯文本而没有时间戳时，不会伪造逐行同步。

### 1.4 精简优化

保持单行菜单栏歌词，没有新增设置面板或运行依赖。

- 修复间奏与结尾空时间标记不清除上一句的问题。
- 同时间戳的双语歌词合并显示，兼容 LRC 偏移量与逐字时间标记。
- “重新匹配歌词”会真正重新查询，不再直接返回旧缓存。
- 减少重复脚本编译和不必要的界面更新。
- 压缩猫咪图标，保留透明圆角与高分辨率尺寸。

### 1.4.1 稳定性修正

- 停止播放时取消匹配和待重试请求；恢复播放后重新识别。
- 断网时停止重复尝试不同接口，保留最多两次自动重试。
- 回退匹配结果也会缓存，并保留歌手核对提示，减少重复联网。
- 校验歌曲时长和播放进度，避免异常数据被当作正常播放。
- 缓存常用正则表达式，减少搜索匹配时的重复处理。

缓存仅保存在内存中，最多 100 首，退出即释放；本应用不会后台下载歌曲或额外组件。

## 卸载

1. 退出“嗷嗷状态栏歌词”。
2. 在“应用程序”文件夹中将它移到废纸篓。

如果还要清除自动化权限，可在“系统设置 → 隐私与安全性 → 自动化”中关闭对应权限。

## 从源码构建

需要 macOS 13 或更高版本及 Apple Command Line Tools：

```sh
git clone https://github.com/sange1022/aow-statusbar-lyrics.git
cd aow-statusbar-lyrics
./build.sh
```

生成的应用位于 `build/嗷嗷状态栏歌词.app`。制作 DMG：

```sh
./make-dmg.sh
```

运行回归测试：`./test.sh`。开发时构建并启动：`./script/build_and_run.sh`。

当前安装包适用于 Apple Silicon Mac，最低 macOS 13；应用使用临时签名，尚未经过 Apple 公证。

## 歌词来源

歌词数据由 [LRCLIB](https://lrclib.net) 提供。匹配时仅发送当前歌曲的名称、歌手、专辑和时长；不会读取或上传 Apple Music 账户信息。
